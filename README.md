##  Featured Project: Cricbuzz LiveStats

A full-stack cricket analytics dashboard that combines live API data with a SQL database.

**[→ View the Repository](https://github.com/riniyamary262/CRICBUZZ-LIVESTATS)**

### What it does
-  Fetches live match data from the Cricbuzz API via RapidAPI
-  Stores and queries data in a normalized SQLite database
-  Runs 25 progressive SQL queries (Beginner → Advanced) from a Streamlit UI
-  Full CRUD operations for managing player records
-  Retry logic, transaction rollback, and graceful error handling

### Tech used
`Python` `Streamlit` `SQLite` `Requests` `Pandas` `REST API`

### Highlights
- **Modular architecture** — clean separation into `api/`, `services/`, `utils/`, `pages/`, `sql/`
- **Advanced SQL** — CTEs, window functions, self-joins, and analytical aggregations
- **Production practices** — secrets management, retry with exponential backoff, context-managed DB connections
